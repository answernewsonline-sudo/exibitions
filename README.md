# Room One: 3D gallery prototype

Static, single-file Three.js gallery room (Three.js 0.160.0 from jsDelivr, fonts from Google Fonts). No build step.

- `index.html`: deployable page. Drop the folder on any static host (Netlify, Vercel, GitHub Pages, S3). Opening it from disk may fail because ES modules need http(s); run `npx serve .` to preview locally.
- `gallery.html`: same page without the HTML shell (used for the Claude artifact preview).

## Controls
- Desktop: drag to look, click floor to walk, click artwork for its label, WASD/arrows to move (Q/E or ←/→ turn, Shift faster), wheel to step, `[` `]` previous/next, Esc closes the label.
- Touch: drag to look, tap floor to walk, tap artwork for its label.

## Editing content
Works are the `WORKS` array near the top of the script. Each painting is generated by a function in `PAINTERS`. To use real images, replace the `canvasTex(...)` call for the artwork with `new THREE.TextureLoader().load("images/xyz.jpg")` and set `w`/`h` in cm.

Room size: `RX`, `RZ`, `RH` (half-width, half-depth, height in metres). Wall positions: `wall` (N/W/E) and `at` (metres along the wall).

## Blender
`room-one.glb` is the room exported from the page (File › Import › glTF 2.0 in Blender). Objects are named `Room_*`, `CatNN_<title>_Frame/Mat/Canvas/Label`, plus picture lights. Units are metres, Y-up in glTF (Blender converts to Z-up on import). Light strengths come across roughly; re-light in Blender. Painting textures are embedded PNGs.

`room-one.blend` (Blender 5.3, textures packed) is built from the GLB by `build_blend.py`: objects sorted into Room / Artworks / Lighting collections, imported lights replaced with three skylight area lights and a spotlight per work, entrance camera at eye height, Cycles 64 samples. `room-one-render.png` is a render of that camera. Rebuild with `blender -b -P build_blend.py`.
